# 슬라이드 디자인 시스템

비즈니스 제안서 스타일. 네이비·블루 단색 계열에 흰 배경, 깔끔한 고딕체, 원형·육각형 도형으로 구성한다.

## 1. 기본 설정
- 비율: 16:9 (13.33 × 7.5 in)
- 여백: 좌우 0.5 in, 위 0.4 in, 아래 0.4 in
- 배경: 본문 슬라이드는 흰색, 표지·간지는 네이비

## 2. 색상
| 역할 | 이름 | HEX | 쓰임 |
|---|---|---|---|
| 주색 | Navy | `#1F3A75` | 표지·간지 배경, 하단 반원, 이름 띠 |
| 포인트 | Blue | `#1A5CF0` | 제목 번호, 세로 막대, 아이콘 원, 카드 배경 |
| 보조 | Light Blue | `#E8EFFD` | 연한 배경, 구분선 |
| 강조 | Orange | `#F26B21` | 로고 등 아주 작은 포인트에만 |
| 제목 글자 | Dark | `#222222` | 제목, 소제목 |
| 본문 글자 | Gray | `#666666` | 설명문 |
| 보조 글자 | Light Gray | `#999999` | 부제, 페이지 머리말 |
| 바탕 | White | `#FFFFFF` | 본문 배경, 네이비 위 글자 |

- 한 슬라이드에 블루 계열 + 회색만 쓴다. 오렌지는 슬라이드당 1곳 이하.

## 3. 글꼴
- 글꼴: 맑은 고딕 (영문·숫자도 동일)
- 굵기: 제목 Bold, 본문 Regular

| 요소 | 크기(pt) | 굵기 | 색 |
|---|---|---|---|
| 표지 제목 | 40 | Bold | Dark |
| 간지 번호 (`01`) | 72 | Light/Regular | White |
| 간지 제목 | 32 | Bold | White |
| 슬라이드 제목 | 24 | Bold | Dark (번호는 Blue) |
| 부제(제목 아래 한 줄) | 11 | Regular | Light Gray |
| 소제목·카드 제목 | 16 | Bold | Dark 또는 White |
| 본문 | 12 | Regular | Gray |
| 강조 숫자 (`90%`) | 54 | Bold | White |

- 본문은 한 줄 30자 안팎, 블록당 3줄 이하. 가운데 정렬 블록이 기본.

## 4. 공통 요소 (본문 슬라이드)
- **제목 영역**: 왼쪽 위에 Blue 세로 막대(0.08 × 0.45 in) + `01. 제목을 입력하세요.`
  - 번호 `01.`은 Blue, 제목은 Dark
- **부제**: 제목 바로 아래 한 줄, 11pt Light Gray
- **머리말**: 오른쪽 위에 문서명 작게(8pt Light Gray)
- **로고 자리**: 왼쪽 아래, 높이 0.25 in 이내
- 본문 영역: 제목 아래 1.3 in부터 시작

## 5. 슬라이드 유형
### ① 표지
- 배경: 도시 건물 사진 + Navy 반투명 덮개(투명도 약 30%)
- 가운데 흰 사각형 박스(슬라이드의 약 75% 폭) 안에 로고 → 제목(2줄) → 부제(문서 종류) 순서로 가운데 정렬

### ② 챕터 간지
- 배경 Navy 단색, 겹친 원·세로 줄무늬·점 패턴을 약간 밝은 Navy로 장식
- 왼쪽 중앙: 작은 `Chapter` + 큰 번호 `01` + 제목
- 오른쪽 아래: 점(·) 목록 3~4줄, 10pt White

### ③ 이미지 + 아이콘 3단
- 왼쪽 40%: 육각형 사진 틀
- 오른쪽 60%: Blue 원형 아이콘 3개 → 아래 소제목 → 설명 3줄
- 장식: 오른쪽 위 연한 회색 둥근 사각형, 아래쪽 Navy 반원

### ④ 키워드 + 강조 수치
- 왼쪽 25%: 강조 문구(16pt Bold) → `01`, `02` 번호 목록 → Blue 박스 안 강조 숫자(`90%` + 위쪽 화살표)
- 오른쪽 75%: 말풍선 꼬리 달린 Blue 원 3개(`키워드`) → 소제목 → 설명 → Blue 테두리 카드(위쪽 Blue 띠 + 아래 흰 칸)

### ⑤ 인물 소개 5단
- `• Key members` 소제목
- 원형 인물 사진 5개 가로 정렬 → Navy 이름 띠(`김○○ 과장`) → `학력`, `경력` 점 목록

### ⑥ 핵심 요약 + 카드 4단
- 위: `Key word` 라벨(Blue) + 가로 구분선
- 가운데: 왼쪽 강조 질문(18pt Bold) / 오른쪽 설명 단락
- 아래: Blue 카드 4개 가로 정렬(카드 제목 White Bold + 흰 선 아이콘)
  - 한 장만 흰 바탕 + Blue 테두리로 바꿔 강조 가능

## 6. 도형·아이콘
- 아이콘: 흰색 선 아이콘을 Blue 원(지름 0.8~1.0 in) 안에 넣음
- 카드: 직각 모서리, 테두리 1pt Blue 또는 채움 Blue
- 사진 틀: 육각형 또는 원형으로 자름
- 그림자·그라데이션·3D 효과는 쓰지 않는다.
- 같은 줄 요소는 크기·간격을 똑같이 맞춘다(3·4·5등분).

## 7. 하지 말 것
- 블루 계열 외의 다른 원색 사용
- 본문 12pt 미만 글자, 한 블록 4줄 이상 문장
- 도형·글상자 겹침, 슬라이드 밖으로 넘치는 글자
- 본문 슬라이드에 제목 영역(세로 막대 + 번호) 빠뜨리기
