# 웹 브라우저 제어 규칙

## 1. 자동 호출 (키워드가 있을 때)
- 사용자 메시지에 다음과 같은 표현이 있으면 바로 Playwright MCP(mcp__playwright__*)를 호출한다.
  - "브라우저를 열어서", "브라우저로", "웹 제어", "직접 작업", "직접 들어가서", "사이트에 접속해서" 등
- 이때 Playwright MCP 사용에 대한 동의는 따로 묻지 않는다.
- 단, 파일 생성·수정·삭제가 따르는 작업은 `CLAUDE.md`의 작업 규칙대로 todo list를 먼저 보고하고 승인을 받는다. (브라우저 조회·조작 자체는 승인 없이 진행한다.)

## 2. 동의 후 호출 (키워드가 없을 때)
- 키워드가 없어도 Playwright MCP를 쓰는 편이 낫다고 판단되면, 먼저 이유를 짧게 설명하고 동의를 받은 뒤에 호출한다.
  - 예: 로그인이나 클릭이 필요한 페이지, 동적으로 로드되는 페이지, 화면 확인이나 스크린샷이 필요한 작업
- 사용자가 거절하면 Playwright MCP 없이 다른 방법(WebFetch, WebSearch 등)으로 진행한다.

## 3. 도구 선택
- 브라우저 제어는 Playwright MCP를 기본으로 쓴다. Claude in Chrome은 사용자가 따로 요청할 때만 쓴다.

## 4. 작업 기록
- 스냅샷, 콘솔 로그, 스크린샷은 `.playwright-mcp/`에 둔다. 결과물로 남길 파일은 용도에 맞는 폴더로 옮긴다.
- 작업이 끝나면 브라우저를 닫는다(browser_close).
