# 클로드(Anthropic) 자료조사 v1

- 조사일: 2026-10-13
- 주제: AI 모델 Claude를 만든 회사 Anthropic 소개

## 1. 회사 개요

| 항목 | 내용 |
|---|---|
| 회사명 | Anthropic PBC |
| 설립 | 2021년 1월, OpenAI 출신 연구진이 설립 |
| 주요 설립자 | 다리오 아모데이(CEO), 다니엘라 아모데이(사장) — 남매 |
| 본사 | 미국 캘리포니아주 샌프란시스코 (500 Howard Street) |
| 회사 형태 | 공익법인(Public Benefit Corporation) |
| 자기 소개 | "AI 안전 및 연구 회사(an AI safety and research company)" |

- 목적(공익법인 정관상): "인류의 장기적 이익을 위한 첨단 AI의 책임 있는 개발과 유지"
- 지향점: 신뢰할 수 있고(reliable), 해석 가능하며(interpretable), 조종 가능한(steerable) AI 시스템
- 안전을 하나의 과학으로 다루고, 연구 결과를 제품에 적용하며, 배운 것을 공개적으로 공유한다.
- 지배구조: 이사회는 주주와 장기이익신탁(Long-Term Benefit Trust, LTBT)이 선출한다.
  - 이사회: Dario Amodei, Daniela Amodei, Yasmin Razavi, Reed Hastings, Chris Liddell, Vas Narasimhan
  - LTBT 수탁자: Neil Buddy Shah, Richard Fontaine, Ben Bernanke

## 2. Claude 모델 라인업 (2026년 10월 기준)

| 모델 | 위치 | 상대 속도 | API 가격(입력/출력, 100만 토큰당) |
|---|---|---|---|
| Claude Fable 5.1 | 고난도 추론, 장기 에이전트 작업 | 느림 | $10 / $50 |
| Claude Opus 5.5 | 장시간 에이전트 코딩·지식 작업 (기본 추천) | 보통 | $4 / $20 |
| Claude Sonnet 5.5 | 속도와 지능의 최적 조합 | 빠름 | $2 / $10 |
| Claude Haiku 5.5 | 대량·저지연 작업(분류, 추출, 라우팅) | 가장 빠름 | $0.10~ / $0.50~ |

- 모든 현행 모델: 텍스트·이미지 입력, 다국어, 도구 사용 지원, 컨텍스트 창 100만 토큰, 최대 출력 12.8만 토큰
- 5.5 세대 출시(2차 자료): Opus 5.5(2026-09-22) → Sonnet 5.5(2026-09-28) → Haiku 5.5(2026-10-07)
- 그 밖의 모델 계열: Mythos
